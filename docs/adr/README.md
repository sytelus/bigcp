# Architecture decision records

ADRs 0001-0025 seed the frozen plan's decisions. ADR 0026 records the
implemented checkpoint-identity hardening. ADRs are append-only: supersede an
old decision with a new numbered ADR rather than rewriting history. Contract,
persistence-format, invariant, and default-profile changes require an ADR.

The index is filename ordered. `docs/MAINTENANCE.md` maps decisions to code and release checks.
